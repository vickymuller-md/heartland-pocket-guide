# Rural HF Pocket Guide v0.2.0

This reference-only, zero-login static PWA release consolidates the reviewed clinical-reference changes since v0.1.0. It includes corrected pharmacotherapy evidence populations and endpoints, finerenone monitoring, individual sodium-plan wording, dated cost/billing context, and explicit clinician-directed medication holds. The symptomatic low-pressure threshold and provider-contact responsibility are preserved.

The published Toolkit V3.4 is a separate artifact (doi:10.5281/zenodo.23073640). This guide incorporates selected reconciliations but does not claim to reproduce every page or replace the full toolkit. Historical gallery images retain their provenance; prototype cards and institution-specific policies are not authorized for patient distribution by this software release.

The dependency update addresses the package advisories found at release preparation. The static build, reference assertions, service-worker precache and offline route behavior are verified separately from clinical suitability. No patient data, real-world outcomes, institutional adoption or prospective clinical validation are included.

Code remains MIT; clinical content remains CC BY-NC 4.0. The HEARTLAND risk framework is proposed and unvalidated. The historical Software Heritage snapshot and v0.1.0 DOI continue to identify their original artifacts.
